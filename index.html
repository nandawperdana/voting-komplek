Voting sudah ditutup

Terima kasih atas partisipasi Anda. Voting Ketua RW sudah ditutup oleh panitia, jadi suara baru tidak bisa lagi dikirim.

1

Masukkan Token Pemilih

Token ada di undangan tertulis yang dibagikan panitia ke tiap rumah (kertas, satu undangan per rumah). Bawa undangan itu ke bilik suara. Satu token hanya bisa dipakai satu kali.

Masukkan token Anda untuk memilih. Huruf besar/kecil tidak masalah.

2

Pilih Kandidat

Ketuk salah satu kartu di bawah ini untuk memilih. Anda hanya bisa memilih satu kandidat.

3

Kirim Suara

Periksa lagi pilihan Anda, lalu tekan tombol di bawah ini. Suara tidak bisa diubah setelah dikirim.

Hasil Voting

Hasil tidak ditampilkan di halaman ini selama voting berjalan. Hasil baru dibuka panitia setelah voting ditutup, dari rekap di Google Sheet (Hasil_Suara).

Untuk Panitia (ketuk untuk membuka)

1) Bagikan satu token per rumah lewat undangan tertulis (kertas) — satu undangan per rumah, dari file token_rumah_200.csv. Daftar rumah masih belum final, jadi jangan cetak undangan sebelum daftar final.
2) Pemilih datang ke bilik suara dan voting di perangkat panitia. Setelah satu pemilih selesai, tekan "Pemilih Berikutnya — Bersihkan Layar" supaya token dan pilihan pemilih sebelumnya tidak terlihat pemilih berikutnya.
3) Di Google Sheet, sheet Daftar_Token menunjukkan token mana yang sudah dipakai.
4) Sheet Hasil_Suara hanya berisi pilihan, tanpa token — jadi pilihan tiap rumah tetap anonim. Jangan buka / umumkan hasil sementara selama voting berjalan.
5) Menutup voting: ubah sel A2 di tab Status jadi Ditutup — halaman otomatis menampilkan "Voting sudah ditutup" dan menolak suara baru.
6) Jangan bagikan token orang lain, dan jangan ubah sheet Hasil_Suara secara manual selama voting berjalan.
